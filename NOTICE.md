# NOTICE

## Project status

This package is an offline recommendation-selection audit derived from the
original `dsh-bili-qq` project. The Bilibili client, QR login, favorite/comment
features, channel delivery, QQ Bot integration, wake scheduler, and their
vendored dependencies have been removed.

## Third-party code

No third-party source code is vendored in this package. Runtime code depends
only on Node.js built-ins.
